# Enterprise Review Note

The previous 9 capsules focused heavily on early game exploration and automation. The newly available bracket_3 skill school (manual) along with the introduction of the specialist deep bore horologist vendor set the stage for deeper progression.

The Keystone Connector "Depth Calipers Bench" merges these elements together. It provides a non-consumed station requirement (using the clockwork siphon rig from bracket 2) to link with the deep bore horologist. In addition, it integrates the previously orphaned stormbreaker geode ore into its price requirement and mechanically consumes it to provide long term benefits via the newly unlocked UI calipers, tying the tectonic crucible lore back into gameplay.
