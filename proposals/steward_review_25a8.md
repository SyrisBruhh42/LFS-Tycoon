# Steward Review Note

The previous 9 capsules effectively expanded the mid-tier crafting graph, but left several key components under-utilized. Specifically, the deep-bore horologist NPC had no offers, and vitriol crystals remained an orphan block. This Keystone Connector bridges these gaps by anchoring the horologist as an essential vendor, introducing a skill mastery node that acts as a permanent upgrade for auto-tool mechanics, and providing a meaningful sink for vitriol crystals.
